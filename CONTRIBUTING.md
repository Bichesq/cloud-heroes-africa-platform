# Contributing

Thanks for contributing to the Cloud Heroes Africa platform.

## Contribution Model

This repository has a lead-developer workflow with collaborative experimentation.

- Bichesq maintains the central direction of the implementation.
- Contributors may propose improvements through branches or forks.
- Experiments are welcome, but they should be clearly documented.
- Good ideas can be reviewed and merged back into the main direction.

## Before You Start

Please read:
- `README.md`
- `docs/architecture.md`
- `docs/ai-workflow.md`
- `docs/git-standards.md`

## Contribution Rules

- Work from documented requirements.
- Keep changes focused and reviewable.
- Use branch names from `docs/git-standards.md`.
- Use clear semantic commit messages.
- If using AI, explain how it was used.
- Avoid mixing unrelated changes in one PR.

## Experiment Branches

Use experiment branches when testing:
- alternate prompting strategies,
- alternate implementation structures,
- different Claude workflows,
- or different skill/agent approaches.

## Pull Requests

Open a PR when:
- the work is scoped,
- the change has been reviewed locally,
- the branch is ready for team review,
- and the description clearly explains the intent.
