Renders a glyph from the CHA icon set (38 icons) with `currentColor`. Recolor via CSS `color`; size with the `size` prop.

```jsx
<Icon name="search" size={20} />
<Icon name="arrow-forward" size={16} style={{ color: 'var(--cha-blue-500)' }} />
```

Use friendly aliases (`house`, `folder`, `settings`, `search`, `plus`, `close`, `star`, `comment`, `chevron-right`, `arrow-forward`, `logo-google`, …). See `Icon.d.ts` for every valid name.
