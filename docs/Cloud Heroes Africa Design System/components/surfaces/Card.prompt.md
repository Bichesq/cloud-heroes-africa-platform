The primary surface — a white panel with soft shadow and generous rounding. Colored variants power feature cards.

```jsx
<Card padding={22} radius={22}>…</Card>
<Card variant="orange" padding={26}>Resume Where You Left Off →</Card>
```

Variants: `default` (white + shadow), `outline`, `sunken`, `dark`, `orange`, `ocean`, `accent`. Props: `padding`, `radius`. Colored cards drop the shadow; nest a white inner panel for stat callouts.
