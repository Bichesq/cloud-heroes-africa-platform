Sidebar navigation row. Active state is a filled pill (orange in the product shell).

```jsx
<NavItem icon={<Icon name="house" size={20} />} active>Dashboard</NavItem>
<NavItem icon={<Icon name="folder" size={20} />} badge="New" chevron>Courses</NavItem>
```

Props: `icon`, `active`, `activeTone` (`orange | dark | soft`), `badge`, `chevron`.
