Pill-shaped action button — CHA's primary interaction control. Use `variant="primary"` (orange) for the main CTA on a view; there should usually be only one.

```jsx
<Button variant="primary" iconRight={<Icon name="arrow-forward" size={16} />}>Resume Learning</Button>
```

Variants: `primary` (orange), `accent` (blue — "Create Event"), `dark` (near-black), `secondary` (soft gray), `outline`, `ghost`, `danger`. Sizes: `sm | md | lg`. Props: `iconLeft`, `iconRight`, `block`, `disabled`.
